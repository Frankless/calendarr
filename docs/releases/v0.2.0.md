## Nouveautés

- **Surprends-moi en swipe** : trois piles de cartes (Pour moi, Pour nous deux, Pour la famille). Gestes
  ou boutons :
  - → oui : le titre est programmé dans le prochain créneau qui lui convient ;
  - ← non : il n'est plus jamais proposé ;
  - ↑ déjà vu : il est marqué vu, et un film l'est aussi dans Jellyfin ;
  - ↓ plus tard : il revient dans deux semaines.

  Un bouton annule le dernier choix. Les flèches du clavier marchent aussi.
- **Match à deux** : dans « Pour nous deux », chacun swipe sur son compte. Si vous dites oui tous les deux,
  c'est un match : le film est programmé et rejoint « Vos matchs ».
- **Mémoire des choix** : le programme de la semaine tient compte de vos oui et de vos non.
