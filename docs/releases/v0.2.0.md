## Nouveautés

« Surprends-moi » se joue maintenant en swipe, avec trois piles de cartes : Pour moi, Pour nous deux,
Pour la famille. Vers la droite, le titre est programmé dans le prochain créneau qui lui convient. Vers
la gauche, il n'est plus jamais proposé. Vers le haut, il est marqué vu, et un film l'est aussi dans
Jellyfin. Vers le bas, il revient dans deux semaines. Les boutons et les flèches du clavier font la même
chose, et un bouton annule le dernier choix.

Dans « Pour nous deux », chacun swipe sur son compte. Si vous dites oui tous les deux, c'est un match :
le film est programmé et apparaît dans « Vos matchs ».

Le programme de la semaine tient compte de ces choix. Un titre refusé ne revient plus, un titre aimé
passe en priorité.
