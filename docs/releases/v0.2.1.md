## What's new

- New setting in Réglages → Le rythme: how often Calendarr reads Radarr, Sonarr and Jellyfin again
  (10 minutes to once a day, every hour by default), with a "Relire maintenant" (Read now) button and the
  time of the last read. Actions such as "On l'a vu" still read Jellyfin right away.

## Fixes

- "Idée" (idea) cards had a thick dashed border; it is now a thin, discreet line.
- README screenshots show the current interface.

## Data

`settings.json` gains a `refresh_minutes` field, ignored by earlier versions.

## Updating

Image `ghcr.io/frankless/calendarr:latest`: stop the project, update the image, start it again.
